# Conceito de corridas da Uber

Projeto estático em HTML5, CSS3 e JavaScript inspirado nas telas do arquivo Figma **PROJETO UBER**.

## Como abrir

Abra `index.html` diretamente no navegador. Não é necessário instalar dependências ou configurar um servidor.

## Fluxos disponíveis

- Tela inicial com serviços sugeridos e locais salvos.
- Busca de destino e escolha de um local.
- Seleção entre UberX, UberX Share e Connect.
- Seleção de horário e forma de pagamento.
- Confirmação da corrida e histórico de viagens.

Os mapas e ilustrações são recursos locais exportados do arquivo Figma. A demonstração não usa API de mapas ou serviço de transporte.
